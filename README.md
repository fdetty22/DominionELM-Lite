# DominionELM-Lite
100% free Rocket League tournament management and broadcasting software. Live overlays, automatic match tracking, tournament brackets, and post-game graphics. No paywalls. No subscriptions. No strings attached. Developed by Detty Productions.

### Windows Security Notice

DominionELM Lite is currently in beta, and its executables are not yet digitally code-signed. As a result, Windows SmartScreen may display an unrecognized publisher warning.

Always download DominionELM Lite from our official GitHub repository. SHA-256 checksums are provided with every release to verify download integrity.

Code signing is planned for a future release as community support grows.

### Privacy

DominionELM Lite is designed with privacy and local-first functionality in mind.

Your teams, organizations, tournaments, match history, logos, and application settings are stored locally on your computer. No Dominion account is required.

Internet connections may be made to check for application updates through GitHub. External links to Discord, GitHub, and Ko-fi open in your default web browser.

Your tournament and match data is not uploaded to Dominion servers.
